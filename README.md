# 🚀 Professional Resume & Portfolio Builder

A modern, high-performance, and fully responsive **Resume Builder** web application built with **Next.js (App Router)** and **Zustand**. Designed for developers and professionals to create, preview in real-time, and export clean, high-quality resumes effortlessly.

---

## ✨ Features

- **Real-Time Live Preview:** Instant synchronization between form inputs and the resume template without page reloads.
- **Dynamic Sections:** Add and remove work experiences, education history, and skills dynamically.
- **Print & PDF Export Engine:** Optimized with custom CSS print styles to export professional A4-ready PDF files directly from the browser without heavy external libraries.
- **Modern Tech Stack:** Built with clean architecture, state management, and strict TypeScript types.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **State Management:** [Zustand](https://github.com/pmndrs/zustand)
- **Icons:** Lucide React

## 📦 Getting Started Locally

Follow these steps to run the project on your local machine:

1. **Clone the repository:**
    ```bash
    git clone [https://github.com/sliman-lan/your-repo-name.git](https://github.com/YOUR_USERNAME/your-repo-name.git)
    ```
2. **Navigate to the project directory:**
    ```bash
    cd your-repo-name
    ```
3. **Install Dependencies**
    ```bash
    npm install
    ```
4. **Run the development server**
    ```bash
    npm run dev
    ```
5. **open your browser**
   Open http://localhost:3000 to view the application.
